Sheet order is random every time. Generating again gives you a different set.

How to run a drill

  • Read one problem at a time and write the algorithm as numbered steps before any code.
  • Fix the loop bounds and the stopping condition out loud — that is where most marks are lost.
  • Then write the code, run it once, and compare your steps with the algorithm list on the problem page.
  • Mark a problem as practised only when you can reproduce its steps from memory the next day.
