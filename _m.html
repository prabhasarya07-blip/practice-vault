How the vault works

Four moves per problem. The code stays your job, so the recall stays in your head.

  1. 1

    Read the statement cold

    Input shape, output shape, constraints. Say the smallest and largest case out loud before anything else.

  2. 2

    Name the pattern

    Traversal, two-pointer, window, hashing, recursion? The bank trains you to classify before you code.

  3. 3

    Write steps, then code

    Numbered plain-language steps first. Loop bounds and stopping conditions fixed before the first line of code.

  4. 4

    Compare and mark

    Open the problem page, compare your steps with the listed algorithm and traps, then mark it practised.

Start here: the order that works

Five topics, sequenced so every new idea leans on the one before it. Number logic builds loop control, patterns force loop bounds, arrays need index discipline, strings need classification, and sorting and searching are the tools you then apply everywhere.
